<p align="center" margin-left="1em">
The Medical AI Assistant is a Retrieval-Augmented Generation (RAG) based application designed to provide concise and accurate answers to medical questions. Powered by LangChain, Hugging Face, and a Pinecone vector database, the bot leverages a dedicated medical knowledge base to ensure its responses are grounded in factual information. This project showcases a complete RAG workflow, including data vectorization, efficient retrieval, and conversational memory, all accessible through a simple Flask-based server.

## 💻 Built with

### Core Frameworks & Tools
- **LangChain**: The primary framework for orchestrating the RAG pipeline.
- **Hugging Face**: Provides the core models for text encoding and chat generation.
- **Pinecone**: The vector database used for storing and retrieving medical knowledge.
- **Flask**: A lightweight web framework for the user-facing server.

### Other Technologies
- **CSS3**: For styling the web pages.
- **`python-dotenv`**: For secure management of API keys.
- **Git**: Version control system.
- **npm**: Node Package Manager (if using a front-end build step).
- **VS Code**: Popular integrated development environment.
- **NLP (Natural Language Processing)**: The core field driving the application's functionality.
